# java-learning

目标：把问题写成可运行的程序，能解释每一步，并能独立修改它解决变式。

从[当前任务](docs/learning.md#当前任务)继续：先预测和尝试，再运行核对，记录首个错误与修正。完成一道题后再决定下一步。

| 需要什么 | 只在这里维护 |
| --- | --- |
| 当前题、能力证据、关键纠错 | [学习记录](docs/learning.md) |
| 已完成程序、预期输出、运行方法 | [练习指南](practice/README.md) |
| 早期原答与原始错误 | [原始片段 A01～A09](docs/original-snippets.md) |

保留内容的标准：能提供真实作答证据、解释一个具体障碍，或检验程序是否正确。相同代码与状态只存一处，其他位置链接；同一知识点的不同原答仍保留，不把测试通过当作独立掌握。

维护规则见 [AGENTS.md](AGENTS.md)。
