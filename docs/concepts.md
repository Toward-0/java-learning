## 怎样使用示例

每个 Java 代码块独立看待。标为“完整程序”的示例按所写公开类名保存为同名文件；其余是方法内片段，可分别放入传统 `main` 中运行。不要把不同块直接拼接成一个文件。

先预测输出，再执行，再解释与预测不同的第一步。完整原答无需为演示重新复制；课堂讲解保留在本集合。

各章附 Java 25 官方语言规范或 API 链接，进一步细节按需查证。
