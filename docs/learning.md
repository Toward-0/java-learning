### A08：年龄输入

2026-09-18 · 原答 [A]；说明与订正 [C]。

```java
Scanner scanner = new Scanner(System.in)；
System.out.println("请输入你的年龄：");
int age = scanner.nextInt();
int sum = age +1;
System.out.println("你今年"+age+"岁，明年"+sum+"岁。");
```

教学记录：第一行的全角分号 `；` 应改为半角 `;`；还需补 `import java.util.Scanner;`、类和 `main` 外壳才能运行。原始错误保留在上方，订正不覆盖原答。

## 循环与累加

<a id="a01"></a>

### A01：偶数累加

2026-09-24 · 原答 [A]；说明与订正 [C]。

```java
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if(i % 2 == 0){
        sum = sum + i;
        System.out.println(sum);
    }
}
```

说明：这段打印的是每次命中偶数后的**累计值**，而不只是最终总和；不能将其注释写成只输出一次。

核查 [C]：依次输出 `2、6、12、20、30`，每个数字占一行。

### A09：循环填空

2026-10-08 · 原答 [A]；说明与订正 [C]。

- 倒三角内层循环条件：`j <= 6-i`
- 输入 0 时的判断：`num == 0`
- 跳出循环：`break`（作为独立 Java 语句需补 `;`）

这些只是用户对助手所给代码框架的局部填空，不能标记为“用户独立完成了整份程序”。
