# 循环与状态

[知识目录](../concepts.md) · [前置：条件](02-expressions-and-branches.md)

## 循环压缩的是重复规则

循环不只是“少写几行”，而是让同一条规则作用于不同状态。写循环前确定：**初始状态、继续条件、本轮动作、状态更新**。

```java
int sum = 0;
for (int i = 1; i <= 3; i++) {
    sum += i;
}
System.out.println(sum);
```

输出6。顺序是：初始化一次 → 检查条件 → 执行循环体 → 更新 `i` → 再检查。

| 本轮开始的 i | 本轮开始的 sum | 更新后的 sum |
| --- | --- | --- |
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |

`i` 更新为4后条件失败，循环体不再执行。把边界改成 `< 3`，只处理1和2；边界来自题目范围，不能凭习惯决定。

## for、while、do-while

| 形式 | 检查位置 | 常见用途 |
| --- | --- | --- |
| `for` | 循环体之前 | 下标、次数、明确更新规律 |
| `while` | 循环体之前 | 重复直到输入或状态发生变化 |
| `do-while` | 循环体之后 | 至少执行一次，再决定是否继续 |

下面说明“至少一次”的差别：

```java
int n = 0;
while (n > 0) {
    System.out.println("while");
}
do {
    System.out.println("do");
} while (n > 0);
```

仅输出 `do`。`do-while` 末尾需要分号。循环语义见 [JLS §14.12–14.14](https://docs.oracle.com/javase/specs/jls/se25/html/jls-14.html#jls-14.12)。

## break、continue、return

| 语句 | 作用 |
| --- | --- |
| 无标签 `break` | 退出最近一层循环或 switch |
| 无标签 `continue` | 跳过最近一层循环的本轮剩余部分 |
| `return` | 结束当前方法，必要时带回结果 |

基本 `for` 中，`continue` 后仍执行更新部分；`while` 中没有自动更新，要检查是否跳过了关键更新语句，否则可能一直处理同一状态。嵌套循环中的无标签 `break` 不会自动结束全部循环。

```java
for (int i = 1; i <= 5; i++) {
    if (i == 2) {
        continue;
    }
    if (i == 4) {
        break;
    }
    System.out.println(i);
}
```

输出1、3，各一行。2被跳过，4触发退出，5未执行。

## 循环不变式：每一步都保留的事实

求和例子中，进入第 `i` 轮前，`sum` 等于1到 `i-1` 的和。核对三步：

1. 初始 `i=1`，尚未处理元素，和为0。
2. 加入 `i` 后得到1到 `i` 的和，下一轮仍满足同一描述。
3. 结束时 `i=4`，因此 `sum` 包含1到3。

这说明了**若循环结束，结果为什么正确**。还要说明它会结束：`i` 每次加1，最终超过3。不变式与终止条件解决两个不同问题。

数组中的计数、求和、最大值也可以用“变量概括已处理部分”解释，见[数组](04-arrays.md#accumulation)。

## 嵌套循环与输出位置

```java
for (int row = 1; row <= 2; row++) {
    for (int col = 1; col <= 3; col++) {
        System.out.print("*");
    }
    System.out.println();
}
```

输出两行 `***`。外层选行，内层处理这一行的列；换行放在内层之后。这里总共打印 `2 × 3` 个星号；若内层次数随行号变化，应逐行相加，不能一律当作固定乘积。

累加变量放在循环外，才能保留跨轮状态。输出放在循环内显示过程，放在循环外显示最终结果；[A01/A02 原答](../learning.md)体现了这个区别。

检验理解：除了“最后打印什么”，还能否逐轮写出变量值，并说明循环为什么会结束？
