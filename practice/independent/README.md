# 用户独立完成的程序

[返回首页](../../README.md) · [练习指南](../README.md) · [学习记录模板](../../docs/learning-log.md)

本目录目前仅有保存规则，没有新增的已完成练习。已有 loops/、arrays/ 示例及其 [A][B][C] 来源说明保持不变。

未来收到用户独立完成的完整程序后：

1. 按实际提交日期建立 `YYYY-MM-DD/` 目录，保存用户提供的 `.java` 原文；不补造代码、日期或完成记录。
2. 文件名与 `public class` 名称一致。若用户提交的是 `public class Main`，保留 `Main.java`，不同练习使用不同子目录；分别编译，不要求全仓库一起编译。
3. 在现有[学习日志](../../docs/learning-log.md)中复制一份空白模板，填写状态、源码相对路径、运行结果及收到的帮助。只保存源码一份，用链接关联日志。
4. 不用纠错版本覆盖第一版作答。用户后续修订可另存版本；AI 补全的类、main、输入或测试数组必须标为 [C]，不计作独立作品。
5. 只有零散片段、未通过编译或仍需补全时，先在学习日志中保留原文并标为“尝试中”，不创建“已完成”程序。

第 26 题继续保持未作答；本目录不提供答案。只有收到用户实际作答后才能如实记录。

现有 GitHub Actions 只检查既有五个无输入程序；未来新增独立程序不会自动加入，确认输入方式与预期结果后再调整工作流。
