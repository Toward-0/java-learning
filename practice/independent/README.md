# 独立完成的练习

[返回首页](../../README.md) · [学习状态与日志](../../docs/learning.md)

本目录用于**未来真实独立完成的完整 Java 程序**。现在只有规则，没有预先生成的题目或答案。

- 按真实提交日期创建 `YYYY-MM-DD/` 子目录；文件名与 `public class` 一致。不同目录可以有同名 `Main.java`，各自编译。
- 每个练习只保存一份正式源码；第一次有意义的版本先提交 Git，后续修改可通过 Git 历史查看，不新增 `final2.java` 等重复副本。
- 在 [docs/learning.md](../../docs/learning.md) 记录状态、完成方式、源码路径、关键错误和运行证据；**不要复制整个源文件**。
- 零散作答、未能独立完成的程序先在学习日志中保留必要原文，或明确标为 AI 补全；不要称作独立作品。

GitHub Actions 会逐个编译本目录内的 `.java` 文件；但仅对已有五个教学程序核对固定输出。编译成功不代表独立掌握。
